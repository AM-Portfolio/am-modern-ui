# Terminal Execution & Transparency Rule

1. **Provide Clear Terminal Commands**: Whenever running builds, tests, or workflows, always display the exact command clearly in the chat so the user can follow along or execute it directly in their VS Code terminal.
2. **Real-time Status Updates**: For long-running commands (e.g. Flutter builds, iOS compilation, pod installs), provide immediate, visible progress updates and log summaries rather than silent background execution.
3. **Prefer Interactive Terminal Visibility**: Ensure the user can track what is going on at every phase of the build and deployment process.

# Workspace Rules for am-modern-ui

## Terminal Execution & User Transparency
1. Always display the exact terminal command in responses so the user can easily follow along or run it directly in their VS Code terminal.
2. For long-running operations (Flutter builds, iOS compilation, pod install), prefer verbose or transparent modes so the user can observe progress in real-time.
3. Keep the user informed with clear, step-by-step terminal outputs rather than hiding behind silent background tasks.
